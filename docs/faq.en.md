# FAQ

## Do I need to create an account to use Jandig?

Yes. Uploading Markers and Objects, and creating Artworks, requires a
Jandig account ([https://jandig.app](https://jandig.app)). You don't
need an account to view Artworks and Exhibitions — just open the
Exhibition link and point the camera at the Marker.

## Do I need to upload my own Marker and Object to create an Artwork?

Not necessarily. When creating a Jandig Artwork you can choose any
Marker and Object already on the platform, uploaded by you or by other
people, and remix them — you don't need to upload your own first. See
more in [Quick Start](inicio-rapido.en.md).

## Do I need to create an Exhibition to test my Artwork?

No. After creating an Artwork, on your phone use the "Preview" option
in its action menu to open the camera and see how it will look,
without needing to create an Exhibition. An Exhibition is only needed
when you want to publicly share a set of Artworks.

## Do markers need to be black and white?

No. Colored images and gradients are fully supported. The default
black-and-white style we use as a base is a historical reference to
the use of rubber stamps and wheatpaste posters ("lambe-lambes") to
produce markers. See [Hints to produce Tags](marcadores.en.md) for
other best practices (symmetry, square format, etc).

## Do I need to draw the marker's border myself?

No. Just upload any image (PNG or JPG) and Jandig automatically adds
the black border needed for recognition, with a preview of the result
before you save it. More details in [Hints to produce
Tags](marcadores.en.md).

## What file formats can I use for Objects?

GIF, PNG, MP4, WebM and GLB. GLB Objects only work in MR Exhibits (the
Mixed Reality app for Meta Quest). AR Artworks, from the marker-based
mobile site, don't accept GLB. You can also attach an optional audio
description in MP3, OGG or WAV. See more in [Tips for producing
media](media.en.md).

## Is there a maximum file size for Markers and Objects?

There's no hard technical limit, but we recommend keeping files small
to ensure fast loading for the public, especially on mobile
connections. See size recommendations per format in [Tips for
producing media](media.en.md).

## Can I edit a Marker or Object after uploading it?

Yes, as long as you're the one who uploaded it and it isn't being used
by someone else. Go to your profile and use the edit option for the
corresponding Marker or Object. If the edit option isn't available,
it's because someone else is already using that Marker or Object in
their own Artwork — in that case, you won't be able to edit it.

## Can I delete a Marker or Object after uploading it?

Yes, if you're the one who uploaded it and it isn't being used by
someone else. Go to your profile and use the delete option for the
corresponding Marker or Object. If the delete option isn't available,
it's because you have an Artwork using that Object or Marker, or
someone else is already using it in their own Artwork — in that case,
you won't be able to delete it.

unless otherwise stated.

## What's the difference between an AR Exhibition and an MR Exhibition?

An AR Exhibition is for the mobile site, based on Marker recognition
through the phone's camera. An MR Exhibition is for the Meta Quest
Mixed Reality app, and is the only type that accepts GLB (3D model)
Objects.

## Where can I ask for help or report a problem?

You can open an issue on the [project's
GitHub](https://github.com/memeLab/Jandig) or reach out through
Jandig's social media (Instagram, Twitter/X, Facebook or Telegram),
available in the site's footer.
