# Quick Start

1.  Go to [https://jandig.app](https://jandig.app) and create an account.

2.  Go to [https://jandig.app/markers/upload](https://jandig.app/markers/upload),
    upload the image (with a .PNG extension), give it a name and declare the
    author. This image will be recognized by Jandig's camera.

3.  Go to [https://jandig.app/objects/upload](https://jandig.app/objects/upload)
    and upload the GIF or 3D model (in GLB format) with your animation. Jandig
    will display this object over the marker in the camera view.

4.  Click "Create Jandig Artwork", and choose the Marker and Object you just
    uploaded. The Jandig Artwork links the Marker to the Object for
    presentation in augmented reality.

5.  Click "Create Exhibition". Choose one or more Artworks. Give the set a
    title and define its URL. You'll use it to access the set of Artworks you
    create. For example, if you enter "expotest" the final URL to access your
    creation(s) will be `https://jandig.app/expotest`.

Access the final URL you just created, point the camera at the Marker and
watch the magic happen!
