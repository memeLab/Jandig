# Rules for Claude in this repository

- **Never merge a pull request without an explicit request from @vjpixel in
  the conversation.** Green CI, an approving review or a Dependabot PR are not
  enough on their own; ask first.
- **Write all GitHub communication in English**: pull request titles and
  descriptions, comments, review replies, issues and commit messages. This
  holds even when the conversation with the user is in another language. The
  help pages under `docs/` keep their existing languages (Portuguese and
  English).
